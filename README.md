# DropStation

DropStation 是一个基于 Next.js 的轻量文件中转站。它面向临时文件分享场景：上传单个文件后生成短链接，链接在指定时间后失效，文件和元数据保存在本机 `data` 目录中。

## 当前能力

- 临时文件分享：支持游客上传、短链接下载、复制链接和最大 1GB 单文件。
- 过期控制：支持快捷时长和日期选择，分享最长有效期 30 天，过期后不可下载。
- 去重与清理：使用 SHA-256 复用相同文件，过期记录会在相关请求中自动清理。
- 账号与个人中心：支持注册登录、我的分享、删除分享、修改资料、修改密码和头像上传。
- 基础权限：站内页面需要登录，管理后台入口已预留且仅管理员可访问。
- 本地存储：文件、头像和 SQLite 数据库都保存在项目的 `data` 目录。
- 主题体验：支持亮色和暗色主题切换。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SESSION_SECRET` | `default_secret` | JWT 签名密钥，生产环境必须设置为高强度随机字符串。 |
| `SESSION_EXPIRY_DAYS` | `30` | 登录会话有效天数。 |
| `SESSION_RENEWAL_THRESHOLD_DAYS` | `10` | 会话剩余天数低于该值时自动续期。 |
| `SESSION_SECURE` | `false` | 设置为 `true` 时 cookie 仅通过 HTTPS 发送。 |

## 数据目录

应用会自动创建以下目录和文件：

```text
data/
  avatars/
  uploads/
  dropstation.sqlite
```

部署时请确保运行进程对 `data` 目录有读写权限，并按需持久化该目录。
